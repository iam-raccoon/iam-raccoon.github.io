> 신호 · 보행자 · 앞차 · 횡단보도 · 교차로 규칙이 **각자 속도 상한** 을 내고, 그중 **가장 낮은 값** 을 명령 속도로 쓴다. 매 프레임 "누가 속도를 잡았는지" (`cap_by`) 를 기록해서, 차가 이상하게 설 때마다 범인을 바로 찾을 수 있게 했다. 대회에서 15개 항목 중 12개 (속도 · 차로 · 신호 · 횡단보도 · 장애물) 는 5구간 내내 감점 0 이었다.
{: .prompt-info }

## 판단 구조 : 상한의 최솟값

규칙끼리 "누가 이기나" 를 if 문 순서로 정하면 규칙이 늘어날 때마다 순서가 꼬인다. 그래서 모든 규칙이 같은 모양으로 말하게 했다 — **"나는 이 속도 이하여야 한다"**.

```python
def _cap(self, v, limit, name):
    self._caps.append((limit, name))
    return limit if limit < v else v
...
self.cap_by = min(self._caps)[1] if self._caps else "SPEED_LIMIT"
```

속도를 깎는 자리가 18군데다. 이긴 규칙 이름이 주행 기록 `cap_by` 칸에 남는다.

> **`cap_by` 를 만든 이유** — 처음엔 '판단 사유' (`reason`) 만 기록했다. 그런데 사유와 **실제로 속도를 잡은 규칙** 이 다른 경우가 많았다. 사람 때문에 선 줄 알았던 장면이 알고 보니 적신호 규칙이 세운 것이었다. 유령 브레이크 · 영구 정지를 추적하느라 하루를 쓰고 나서 넣었다.
{: .prompt-tip }

## 신호

{% include embed/video.html src='/assets/video/hlfma/red-light-stop.mp4' title='우회전할 교차로에서 초록 → 노랑 → 빨강. 정지선에 섰다가 (RED_STOP) 적색 우회전 (RIGHT_ON_RED)' autoplay=true loop=true muted=true %}

| 규칙 | 하는 일 |
|---|---|
| `RED_STOP` | 정지선까지 `sqrt(2·a·d)` 로 감속 |
| `RED_CLEARING` | 이미 앞범퍼가 0.3 m 넘었고 굴러가는 중이면 빠져나감 |
| 황색 | 제동거리로 설 수 있으면 서고, 못 서면 통과. 단 **서 있던 차는 황색에 출발하지 않음** |
| `TL_UNSEEN` | 신호가 늦게 보고되는 자리 앞에서 미리 17 km/h 쯤으로 |
| `FLASH_STOP` | 점멸은 무조건 일시정지 |
| `RIGHT_TURN_SLOW` | 녹색 우회전은 15 km/h, 적색 우회전은 **적색 중에** 한 번 선 뒤에만 |

**점멸은 서는 쪽으로.** 9910 은 점멸의 색을 주지 않고, 지도의 신호 646개는 크기가 전부 0.40 × 0.41 m 라 생김새로도 구분이 안 된다. 서면 적색 점멸 조건을 지키고, 황색 점멸이어도 위반이 아니다.

**신호가 늦게 보이는 자리.** 어떤 신호는 앞범퍼 **9 m** 앞에서야 처음 보고된다. 37 km/h 로 달리다 9 m 앞에서 적색을 보면 설 수 없다 (실제로 1.9 m 지나쳤다). 그래서 지도에 정지선은 있는데 신호가 아직 안 보이는 곳은 앞 60 m 부터 미리 줄인다.

> **황색 13 cm** — 보행자 때문에 정지선 0.96 m 앞에 서 있다가 출발한 지 0.4 s 만에 황색이 됐다. 그때 0.75 m/s · 정지선까지 0.53 m, 반응 시간 0.8 s 를 넣은 제동거리는 0.66 m. "못 선다" 로 판정돼 그대로 적색에 교차로를 건넜다. 그 뒤 **멈춰 있던 차 (2.0 m/s 미만) 는 황색에 출발하지 않는다**를 넣었다.
{: .prompt-warning }

> **우회전 일시정지를 두 번 고쳤다** — 처음엔 녹색에도 섰다. 서 있는 동안 황 → 적이 되면 "이미 정지했다" 로 보고 적색 직후 출발해서, 두 판에서 중대 −6. 녹색은 15 km/h 서행으로 바꿨다. 그 뒤에도 황색에 0.7 s 섰다가 적색 0.1 s 만에 출발한 판이 나와서, 정지는 **적색 중에 채운 것만** 인정하게 했다.
{: .prompt-warning }

## 보행자

{% include embed/video.html src='/assets/video/hlfma/crosswalk-ped-yield.mp4' title='횡단보도를 건너는 사람 앞에서 4 km/h 까지 늦추고, 사람이 내 차로를 벗어나면 출발 (YIELD_PED → PED_LEAVING)' autoplay=true loop=true muted=true %}

- `YIELD_PED` : 사람 앞 **앞범퍼 5 m**에 선다
- `PED_CAUTION` : 15 m 폭 안에서 내 진로 쪽으로 0.5 m/s 이상 다가오는 사람이 있으면 미리 줄인다
- 횡단보도 위에 사람이 있으면 정지선에 선다. 떠나는 사람은 **내 차로를 지나 한 차로 더** 갈 때까지 센다
- 보호구역 무신호 횡단보도는 사람이 없어도 일시정지 (도로교통법 제27조 ⑦)

> **무단횡단을 두 번 고쳤다** — 처음 로그에는 사람 때문에 선 적이 한 번도 없었다 (세운 건 적신호). 1차로 감시 폭을 `차로 반폭 + 사람 속도 × 내가 도착할 시간` 으로 잡았는데, **가까워질수록 폭이 좁아지는** 모순이 있었다. 녹색 판에서 사람 8.5 m 앞까지 50 km/h 로 달려 1.09 m 로 스쳤다. 2차로 폭을 15 m 로 고정하고 횡방향 속도로 걸렀다. 실여유 1.09 → 4.16 → **4.66 m**.
{: .prompt-warning }

**보호구역 횡단보도는 네 번 고쳤다.** 처음엔 신호에 딸린 횡단보도만 알아서 골목 횡단보도를 아예 몰랐다. 코스 A 의 24곳으로 세어 보면 이렇게 갔다.

| 단계 | 바꾼 것 | 지킨 곳 |
|---|---|---:|
| 구현 전 | | 0 |
| ① | 무신호 횡단보도 정지 | 18 / 24 |
| ② | '근처에서 섰나' 가 아니라 **어디서 섰나**로 셈 | 12 / 24 |
| ③ | 정지선 710개가 좌표 버그로 281곳에 뭉쳐 있던 걸 고침 | 22 / 23 |
| ④ | 횡단보도 본체 좌표도 같은 버그 (최대 10.8 m 이동) | **23 / 23** |

②에서 숫자가 떨어진 건 나빠진 게 아니라 **세는 방법이 정직해진** 것이다. 대가로 코스 한 판에 약 100초가 늘었다.

## 물체 분류 — 크기로

패킷은 물체 종류를 주지 않는다. VTD 카탈로그 **222개**를 전부 놓고 길이 · 폭 · 높이로 가르는 규칙을 만들었다.

```python
if length < 0.20:            return False   # 표지판 0.04 · 폴 0.05 · 삽 0.06
if height >= 1.2:            return max(L,W) < 1.2 or (W <= 1.0 and L <= 3.0)
if height >= 0.85:           return W <= 0.70 and L <= 2.30   # 휠체어 · 자전거
```

| 분류 | 기준 | 대응 |
|---|---|---|
| 사람 · 휠체어 · 자전거 | 위 규칙 | 양보, 옆으로 지날 때 1.2 m |
| 노면 위 물체 | 높이 0.25 m 미만 | 무시 |
| 차 | 길이 2.30 m 이상 · 폭 1.40 m 이상 | 앞차 따라가기 · 추월 |
| 사물 | 나머지 | 피하기 ([④편]({% post_url 2026-09-02-hlfma-04-avoid %})) |

옆 차로를 60 km/h 로 달리는 오토바이에 보행자 양보가 걸려 30 → 10 km/h 로 떨어진 적이 있다. 그래서 **차로 밖에서 달리는 이륜차** 와 40 km/h 보다 빠른 것은 사람으로 보지 않는다.

## 지시등 : 30 m 와 3초 중 긴 쪽

법 (시행령) 은 30 m 전, 대회는 3초 전. 테스트는 경로의 모든 차선변경에서 **둘을 동시에** 만족하는지 본다. 커브는 회전이 아니라서 앞에 교차로가 있을 때만 켠다.

## 제어

| | 값 |
|---|---|
| 조향 | Pure Pursuit, 축거 2.95 m, 앞보기 4 ~ 20 m, 최대 35° |
| 속도 프로파일 | 곡률 기반 2-pass, 횡가속 3.0 · 가속 1.5 · 감속 3.0 m/s² |
| 종방향 | PI, 출력 −5.0 ~ +2.0 m/s² |

2-pass 는 "곡률로 정한 최고 속도" 를 뒤에서 앞으로 한 번 (미리 감속), 앞에서 뒤로 한 번 (완만히 가속) 깎는다.

```python
v = [v_max if kk <= 1e-4 else min(v_max, math.sqrt(a_lat / kk)) for kk in k]
for i in range(n - 2, -1, -1):   # 후방 패스 : 앞의 저속 지점에 맞춰 미리 감속
    v[i] = min(v[i], math.sqrt(v[i + 1] ** 2 + 2 * a_dec * ds[i]))
for i in range(1, n):            # 전방 패스 : 가속 한계로 완만히 가속
    v[i] = min(v[i], math.sqrt(v[i - 1] ** 2 + 2 * a_acc * ds[i - 1]))
```

종점 감속도 선형 램프를 `sqrt(2·a·남은 거리)` 로 바꿨더니 종점 오차가 8.4 → 1.1 m 로 줄었다.
