> 제24회 한국로봇항공기경연대회 VTOL 자율 인명구조 부문에 팀으로 나갔다. 드론이 조난 지점까지 날아가 **조난자 트레이를 집어 오는** 임무다. 내가 맡은 건 트레이를 집는 **그리퍼 설계**, 시뮬에서 **파지를 성공시키는 것**, 그리고 고정익 구간의 **경로점 추종**이었다. 이 글은 그리퍼 이야기. 5일 동안 v1 에서 v22 까지 갔고, 가장 큰 전환은 깔때기를 **거꾸로** 달고 있었다는 걸 알아챈 것과 시뮬로 **병목이 깔때기가 아니라 발톱** 이었음을 찾은 것이었다.

## 임무와 내 몫

이륙 → 고정익 전환 → 경로점 4개를 따라 순항 → 조난 지점에서 다시 회전익으로 → 카메라로 트레이를 찾아 내려가 **집기** → 복귀 순항 → 홈 착륙장 마커 위 정밀 착륙.

시뮬레이션 스택은 ROS 2 Humble + PX4 SITL v1.17 + Gazebo Harmonic 이다. 임무 상태기계 · 비전 · 경로 생성 · 천이 같은 기본 골격과 실기체 공력 반영은 팀원들이 만들었다. 이 연재는 그 위에서 **내가 한 부분**만 다룬다. 레포 : [vtol-autonomous-rescue](https://github.com/headon7373/vtol-autonomous-rescue)

## 트레이는 상자가 아니었다

**v1 (7/23)**은 사각 깔때기에 파지 기구 6종을 붙였다. README 에 스스로 적은 평가가 "트레이를 상자로 오해한 설계". 실제 트레이는 **다리 달린 격자판**이다.

| 트레이 치수 | |
|---|---|
| 테두리 (림) | 237 × 137 mm |
| 윗판 | 220 × 120 mm |
| 림 아래 파인 홈 (언더컷) | 8.5 mm |

집을 곳은 림 아래 8.5 mm 홈이다. 그리고 드론은 정확히 트레이 위에 내리지 못한다. 그래서 설계 목표가 하나로 정리됐다. **착륙 오차를 구조로 흡수하고, 림 아래로 발톱을 넣는다.**

v5 에서는 '정렬이 어디까지 자유로워야 하나' 를 시뮬로 따졌다. 결론은 **회전 자유는 해롭다** (0° 로 내려도 −6° 가 생김), 자유는 앞뒤 · 좌우로만 ±8 mm, 필요한 유격은 **착륙 오차 표준편차의 약 2.5배**.

### v13 : 깔때기가 거꾸로였다

v12 를 들여다보다가 깔때기가 **뒤집혀 있었다**는 걸 알았다. 넓은 입구가 아래 (트레이 쪽) 로 가야 착륙 오차를 받아 낸다. v12 는 좁은 쪽이 아래라서 착륙이 **3 mm 만 어긋나도** 림에 부딪혔다. 180° 뒤집었다.

### v14 : 병목은 깔때기가 아니라 발톱

뒤집어도 잘 안 잡혔다. 착륙 위치를 무작위로 뿌려 여러 번 굴려 보는 **몬테카를로 시뮬** 을 만들어 어디서 막히는지 셌다. 병목은 깔때기가 아니라 **발톱이 림을 받아 줄 수 있는 폭 (±3.2 mm)**이었다. 깔때기가 트레이를 아무리 잘 모아도 마지막 3 mm 에서 걸렸다.

- 발톱 쪽 링크 구멍을 둥근 구멍에서 **8 mm 긴 슬롯 + 압축 스프링**으로 (발톱이 스스로 밀려나며 맞춰짐)
- 목 여유를 ±3.5 → ±8 mm 로

| | 포획률 | 끼임 |
|---|---:|---:|
| 고치기 전 | 2 % | 45 % |
| 목 여유만 넓힘 | 1 % | |
| **발톱 슬롯 + 목 여유** | **91 %** | 9 % |
| + 회전 베어링 | 97 % | |

목만 넓히면 오히려 1 % 로 떨어진다는 게 핵심이었다. 규칙으로 남겼다 — **발톱이 받는 폭 ≥ 목 여유 + 2 mm**.

## v20 → v22 : 스프링도 링크도 없앴다

마지막엔 방향을 바꿨다. 서보 하나가 링크로 발톱 넷을 움직이면, 링크 · 스프링 · 슬라이드의 공차가 다 쌓인다. 그래서 **네 변에 각자 서보 훅** 을 달았다.

- SG90 서보 4개, 신호선은 하나로 병렬
- 스프링 · 링크 · 슬라이드 없음 → 맞춰야 할 공차 0
- 열림 : 갈고리 끝이 위 · 바깥으로 (림 통과) → 닫힘 : 갈고리 끝이 림 아래 8.5 mm 홈으로 들어가 들어 올림
- **하나가 죽어도 나머지 셋이 잡는다**
- 포획 시뮬 98 % (트레이 방향은 카메라로 미리 맞춘다는 전제), 약 **395 g**

v20 을 확정본으로 정리한 게 v22 다.
