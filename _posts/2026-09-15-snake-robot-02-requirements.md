두 번째 과제는 요구도였음. 첫 과제에서 받은 피드백에 답하면서 범위를 좁히고, 사용자 요구를 뽑아 우선순위를 매겼음.

## 피드백에 대한 답

- 실투입용인가, 시제품인가 → 기술 검증 시제품으로 범위를 한정함.
- 케이블이 길면 무겁다, 무선은? → 유선은 유지하고 진입 거리를 3~5 m로 제한함.
- 시뮬레이터는? → Isaac Sim(학습은 Isaac Lab)을 쓰고 실측으로 시뮬을 보정함. 못 따라가면 MuJoCo로 감.
- 시뮬과 실제의 마찰 차이 → 실측으로 보정하고, 학습 때 마찰을 매번 바꿈(도메인 랜덤화).
- 강화학습 전후 비교 → 기본 제어기(M1)를 먼저 만들고 학습 정책(M2)과 같은 조건에서 비교함.
- 시험 절차와 성공 기준 → 요구마다 통과 기준을 두고 6단계 시험 절차를 짬.

관절도 바꿨음. 8개(모두 요)에서 9개(요 7, 피치 2)로 늘림. 고개를 들어 앞을 보고 단차에 올라설 수 있게 하려고.

### 유선

잔해 속 통신 때문에 유선을 골랐음. 무선(배터리 + Wi-Fi)은 잔해 더미에서 60~80 dB 감쇠됨(NIST TN 1540). 유선은 끊김이 없음. 끼었을 때도 유선은 케이블로 당겨 회수할 수 있지만 무선은 회수할 방법이 없음. 전원도 케이블로 받으니 배터리 무게나 사용 시간 제한이 없음. 대신 케이블이 끌리고 어딘가에 걸릴 수 있음. 무선의 단점은 통신 두절임.

### 수동 바퀴

수동 바퀴는 앞뒤로는 구르고 옆으로는 안 밀림. 몸을 S자로 흔들어 바닥을 옆으로 밀면 바퀴가 버티는 힘이 앞으로 가는 힘이 됨. 진짜 뱀은 배 비늘이 이 일을 함. 마찰이 모든 방향으로 같으면 앞으로 못 감.

![같은 관절 명령에서 바퀴 유무에 따른 이동 궤적](/assets/img/snake/why-wheels.png)
_같은 서펜노이드 명령 12 s. 등방성 마찰 2.2 cm, 바퀴(이방성) 171 cm (2D 해석)_

대신 경사와 험지에 약함. 그래서 이때는 범위를 평탄한 공극, 단차 20 mm 이하로 한정했음. 이 결정은 다음다음 과제에서 뒤집힘.

## 사용자 요구 (UR)

현장 사례와 문헌에서 사용자 요구 7개를 뽑았음.

| 근거 | 드러난 문제 | 사용자 요구 |
|---|---|---|
| 광주 화정 아이파크 붕괴 2022, INSARAG 지침 | 잔해에 막혀 접근 불가, 생존 공간으로 들어가야 함 | UR-1 좁은 공간 진입 |
| 화정 2022 | 열화상 드론과 구조견으로 확인 실패, 15일째 내시경으로 확인 | UR-2 요구조자 확인 |
| 울산화력 보일러 타워 붕괴 2025 | 위치 확인에 9일, 확인 뒤에야 굴착 | UR-3 위치 보고 |
| GMD-SNAKE2 2000 | 관절이 많아 조작이 어려움 | UR-4 쉬운 조작 |
| Murphy 2021 | 테더는 잔해에 걸리기 쉬움 | UR-5 끼임 시 회수 |
| NIST TN 1540 | 잔해 더미에서 전파 60~80 dB 감쇠 | UR-6 통신 유지 |
| 설계 판단 | 관절이 한 줄이라 하나 고장이 전체에 영향 | UR-7 고장 시 이동 |

## 참조 규격

재난 로봇 전용 KS는 못 찾았음. 그래서 KS 이동 로봇 시험방법과 ASTM E54(NIST 재난대응 로봇 시험법)를 시제품에 맞춰 썼음.

주행 속도는 KS B 7314, 장애물 접촉과 끼임은 KS B 7312를 준용함(방법만 빌림). 좁은 통로와 단차는 ASTM E54를 시험장 규모만 줄여서 씀. 영상과 통신은 ASTM E54, 비상정지는 KS B ISO 13850을 그대로 적용함. 방진, 방수(KS C IEC 60529)는 시제품 범위 밖이라 뺐음.

## AHP와 QFD

설계 목표 세 개(임무 달성, 안전성, 조작성)를 쌍대 비교했음. 가중치는 0.54, 0.30, 0.16이고 CR은 0.008. 그다음 목표 안에서 UR끼리 다시 비교했음. UR 중요도는 목표 가중치에 목표 안 가중치를 곱한 값임.

QFD는 행에 UR, 열에 정해야 할 설계 특성을 두고 9, 3, 1 관계로 채웠음.

![AHP 사용자 요구 중요도와 QFD 설계 특성 중요도](/assets/img/snake/hw2-ahp-qfd.png)
_UR 공동 1위는 좁은 공간 진입과 요구조자 확인. 설계 특성은 관절 배치(28%), 학습 제어(20%) 순_

그래서 관절 배치를 다음 과제(개념 형상)에서 먼저 정하기로 했음.

## 인수 기준

| 사용자 요구 | 시험 방법 | 통과 기준 |
|---|---|---|
| UR-1 좁은 공간 진입 | 90° 굴절 4회, 폭 100 mm 통로 | 5회 중 4회, 끼임 0 |
| UR-2 요구조자 확인 | 통로 끝 표적 촬영 | 30 cm 이상에서 판독 |
| UR-3 위치 보고 | 추정 거리와 실측 비교 | 오차 ±15 cm |
| UR-4 쉬운 조작 | 조작 입력 개수 | 속도, 조향 2개 |
| UR-5 끼임 시 회수 | 끼임 유도 후 테더로 당김 | 회수 80% 이상 |
| UR-6 통신 유지 | 진입 3 m 지점 영상 | 끊김 없음 |
| UR-7 고장 시 이동 | 관절 1개 힘 풀고 재주행 | 속도 저하 50% 이내 |

이 표의 숫자 중 몇 개는 나중에 바뀜(폭 100에서 150 mm로 바뀐 것 등). 바뀐 이유는 [⑧편]({% post_url 2026-10-07-snake-robot-08-trace-fault %})에 정리했음.
