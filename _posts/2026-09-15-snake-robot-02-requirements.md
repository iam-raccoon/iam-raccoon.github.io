> 범위를 **기술 검증 시제품 · 유선 3 ~ 5 m · 관절 9개 (요 7 + 피치 2)**로 좁히고, 현장 사례와 문헌에서 사용자 요구 7개를 뽑아 AHP · QFD 로 우선순위를 매겼다. 가장 중요한 설계 특성은 **관절 배치 · 학습 제어**.
{: .prompt-info }

## 첫 과제 피드백에 답하기

| 피드백 | 답 |
|---|---|
| 실투입용인가, 시제품인가 | 기술 검증 시제품으로 범위를 한정 |
| 케이블이 길면 무겁다, 무선은? | 유선 유지, 진입 거리를 3 ~ 5 m 로 제한 |
| 시뮬레이터는? | Isaac Sim (학습은 Isaac Lab), 실측으로 시뮬 보정. 못 따라가면 MuJoCo |
| 시뮬과 실제의 마찰 차이 | 실측 보정 + 학습 때 마찰을 매번 바꿈 (도메인 랜덤화) |
| 강화학습 전 · 후 비교 | 기본 제어기 (M1) 를 먼저 만들고 학습 정책 (M2) 과 같은 조건에서 비교 |
| 시험 절차와 성공 기준 | 요구마다 통과 기준 + 6단계 시험 절차 |

관절도 바꿨다. 8개 (모두 요) → **9개 (요 7 + 피치 2)**. 고개를 들어 앞을 보고, 단차에 올라설 수 있게.

### 왜 유선인가

| | 유선 (테더) | 무선 (배터리 + Wi-Fi) |
|---|---|---|
| 잔해 속 통신 | 끊김 없음 | 잔해 더미에서 60 ~ 80 dB 감쇠 (NIST TN 1540) |
| 끼었을 때 | 케이블로 당겨 회수 | 회수 불가 |
| 전원 | 케이블로 공급 | 배터리 무게 · 사용 시간 제한 |
| 단점 | 케이블 끌림 · 걸림 | 통신 두절 |

### 바퀴는 왜 다나

수동 바퀴는 앞뒤로는 구르고 옆으로는 안 밀린다. 몸을 S자로 흔들어 바닥을 옆으로 밀면, 바퀴가 버티는 힘이 앞으로 가는 힘이 된다. 진짜 뱀의 배 비늘이 하는 일이다. 마찰이 모든 방향으로 같으면 앞으로 못 간다.

![같은 관절 명령에서 바퀴 유무에 따른 이동 궤적](/assets/img/snake/why-wheels.png)
_같은 서펜노이드 명령 12 s. 마찰이 등방성이면 2.2 cm, 바퀴 (이방성) 가 있으면 171 cm (2D 해석)_

대가는 경사 · 험지에 약하다는 것. 그래서 이때는 범위를 **평탄한 공극, 단차 20 mm 이하**로 한정했다. (이 결정은 다음다음 과제에서 뒤집힌다.)

## 사용자 요구 (UR)

| 근거 | 드러난 문제 | 사용자 요구 |
|---|---|---|
| 광주 화정 아이파크 붕괴 2022 · INSARAG 지침 | 잔해에 막혀 접근 불가, 생존 공간으로 들어가야 함 | UR-1 좁은 공간 진입 |
| 화정 2022 | 열화상 드론 · 구조견으로 확인 실패, 15일째 내시경으로 확인 | UR-2 요구조자 확인 |
| 울산화력 보일러 타워 붕괴 2025 | 위치 확인에 9일, 확인 뒤에야 굴착 | UR-3 위치 보고 |
| GMD-SNAKE2 2000 | 관절이 많아 조작이 어려움 | UR-4 쉬운 조작 |
| Murphy 2021 | 테더는 잔해에 걸리기 쉬움 | UR-5 끼임 시 회수 |
| NIST TN 1540 | 잔해 더미에서 전파 60 ~ 80 dB 감쇠 | UR-6 통신 유지 |
| 설계 판단 | 관절이 한 줄 → 하나 고장이 전체에 영향 | UR-7 고장 시 이동 |

## 참조 규격

재난 로봇 전용 KS 는 찾지 못했다. KS 이동 로봇 시험방법과 ASTM E54 (NIST 재난대응 로봇 시험법) 를 시제품에 맞춰 쓴다.

| 평가 항목 | 참조 규격 | 적용 |
|---|---|---|
| 주행 속도 | KS B 7314 | 준용 (방법만 빌림) |
| 장애물 접촉 · 끼임 | KS B 7312 | 준용 |
| 좁은 통로 · 단차 | ASTM E54 | 축소 (시험장 규모를 줄임) |
| 영상 · 통신 | ASTM E54 | 적용 |
| 비상정지 | KS B ISO 13850 | 적용 |
| 방진 · 방수 | KS C IEC 60529 | 비적용 (시제품 범위 밖) |

## AHP · QFD

설계 목표 세 개 (임무 달성 · 안전성 · 조작성) 를 쌍대 비교하고 (가중치 0.54 · 0.30 · 0.16, CR 0.008), 목표 안에서 UR 을 다시 비교했다. UR 중요도 = 목표 가중치 × 목표 안 가중치.

QFD 는 행 = UR, 열 = 정해야 할 설계 특성, 9 · 3 · 1 관계로 채웠다.

![AHP 사용자 요구 중요도와 QFD 설계 특성 중요도](/assets/img/snake/hw2-ahp-qfd.png)
_공동 1위 사용자 요구는 좁은 공간 진입 · 요구조자 확인. 가장 중요한 설계 특성은 관절 배치 (28 %) · 학습 제어 (20 %)_

→ 관절 배치를 다음 과제 (개념 형상) 에서 먼저 정하기로 했다.

## 인수 기준

| 사용자 요구 | 시험 방법 | 통과 기준 |
|---|---|---|
| UR-1 좁은 공간 진입 | 90° 굴절 4회 · 폭 100 mm 통로 | 5회 중 4회, 끼임 0 |
| UR-2 요구조자 확인 | 통로 끝 표적 촬영 | 30 cm 이상에서 판독 |
| UR-3 위치 보고 | 추정 거리 vs 실측 | 오차 ±15 cm |
| UR-4 쉬운 조작 | 조작 입력 개수 | 속도 · 조향 2개 |
| UR-5 끼임 시 회수 | 끼임 유도 후 테더로 당김 | 회수 80 % 이상 |
| UR-6 통신 유지 | 진입 3 m 지점 영상 | 끊김 없음 |
| UR-7 고장 시 이동 | 관절 1개 힘 풀고 재주행 | 속도 저하 50 % 이내 |

> 이 표의 숫자 중 몇 개는 나중에 바뀐다 (폭 100 → 150 mm 등). 바뀐 이유를 추적한 이야기는 [⑧편]({% post_url 2026-10-07-snake-robot-08-trace-fault %}).
