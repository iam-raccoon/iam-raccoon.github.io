> 시험 통로 치수를 먼저 정하고 (폭 120 · 높이 80 · 굴절 반경 100 · 단차 20 mm), 사용자 요구 7개를 기능 요구 18개로 나눈 뒤, **요 7 + 머리 피치 2 = 관절 9개, 수동 바퀴 16개** 의 개념 형상을 냈다.
{: .prompt-info }

## 관절 제어만으로 앞뒤가 되나

**추진 원리** : 서보가 시간차를 두고 굽어 몸에 S자 파동 → 각 마디가 바닥을 옆으로 밂 → 바퀴가 옆 미끄럼을 막아 마디에 수직인 반력 → 마디가 기울어 있으니 반력에 전진 성분 → 옆 성분은 번갈아 상쇄, 전진 성분은 누적. 스케이트 날과 같은 원리다.

| 조작 입력 | 관절 굽힘 순서 | 결과 |
|---|---|---|
| 전진 | 머리 쪽 관절부터 | 머리 방향 이동 |
| 후진 | 꼬리 쪽 관절부터 (순서 반전) | 꼬리 방향 이동 |
| 조향 | 파동에 오프셋 | 좌 · 우 선회 |
| 속도 | 파동 주파수 | 속도 증감 |

## 타겟 통로

| 폭 | 높이 | 굴절 반경 | 단차 | 진입 거리 | 바닥 |
|---|---|---|---|---|---|
| 120 mm | 80 mm | 100 mm | 20 mm 이하 | 3 ~ 5 m | 평탄 · 경사 0° |

- 폭 120 = 파동이 차지하는 폭 98 mm (요 7관절, 위상차 60°) + 양쪽 여유
- 높이 80 = 로봇 40 + 단차 20 + 머리 들기 여유 20
- 단차 20 : 바퀴 반경 8 mm 로는 굴러서 못 넘으므로 피치 관절 2개로 머리를 들어 넘음

> 돌이켜 보면 이 숫자들은 **로봇 크기에서 거꾸로 계산한** 값이었다. 다음 과제에서 "근거가 부족하다" 는 지적을 받고, 환경 (실제 공극 실측) 에서 다시 뽑게 된다.
{: .prompt-warning }

## 제약이 설계에 미친 영향

| 제약 | 설계에 미친 영향 |
|---|---|
| 서보 최대 토크 0.52 N·m (XL330) | 몸 전체를 들 수 없어 피치 관절은 머리 2개만 |
| 서보 전압 3.7 ~ 6.0 V | 5 V 공급, 테더가 길면 전압 강하 → 진입 거리 상한 |
| 제어기 포트 합계 3 A | 서보 버스에 외부 전원 직접 분배 |
| 테더 끌림 | 5 m 에서 추진력 약 25 % 손실 |
| 수동 바퀴 | 경사 · 험지에 약함 → 바닥 평탄으로 한정 |

법 · 제도 쪽은 소방장비 분류 (탐색구조장비) 에 잔해 공극 주행 장비 항목이 없고 강제 인증도 없었다.

## 기능 요구 18개

| 사용자 요구 | 기능 요구 |
|---|---|
| UR-1 좁은 공간 진입 | 통로 직진 · 굴절 90° · 단차 · 전진 / 후진 / 조향 |
| UR-2 요구조자 확인 | 전방 영상 · 자체 조명 · 영상 실시간 전송 |
| UR-3 위치 보고 | 진입 거리 추정 (관절 각도 적분) · 진행 방향 표시 |
| UR-4 쉬운 조작 | 조작 입력 2개 · 관절 각도 자동 생성 |
| UR-5 끼임 시 회수 | 후진 복귀 · 관절 힘 해제 · 테더 인장 회수 |
| UR-6 통신 유지 | 유선 통신 · 유선 전원 |
| UR-7 고장 시 이동 | 관절 상태 감시 · 고장 관절 제외 주행 |

임무 시나리오는 준비 (자가진단) → 진입 → 굴절 90° × 4 → 단차 → 확인 (조명 · 촬영 · 전송) → 보고 (진입 거리) → 복귀 (후진, 실패 시 테더 회수) 7단계로 나눠 단계마다 기능 요구를 붙였다.

## 개념 형상

- **배치** : 꼬리 M0 (제어기 OpenRB-150, 테더 인출) + 추진부 (요 관절 7, 수동 바퀴 16) + 머리부 (피치 2, FPV 카메라 + LED)
- **크기** : 전장 약 550 mm, 단면 약 35 × 40 mm, 질량 약 320 g
- **모듈** : 추진부는 같은 모듈 반복 (하나 검증 후 복제), 제어기 · 테더 인출은 꼬리 한 점에

카메라는 아날로그 FPV (14 × 14 mm, 먼 초점, 영상선 1가닥) 를 골랐다. USB 내시경은 초점이 2 ~ 8 cm 고정이라 먼 표적이 흐리고, Wi-Fi 카메라는 잔해 속에서 끊긴다.

**앞바퀴 구동 (피드백)** 은 두 안으로 비교만 했다. 전부 수동 바퀴 (A) 는 파동을 못 칠 만큼 좁은 곳에서 멈추고, 머리 구동 바퀴 (B) 는 구동력으로 빠져나올 수 있지만 서보 하나와 전류가 늘어난다.

## 받은 피드백 — 가장 아팠던 것

- **시험 환경 형상 (굴절 · 장애물) 의 근거가 부족하다**
- 서보 개수 선정 기준은?
- 20 mm 단차가 정말 넘어가나? 관절 각도 범위는?
- 롤 (전복) 대응은? 조작 방식과 자율 수준은?
- GPS 없는 곳에서 위치는 어떻게 아나? 테더 꼬임은?

공통 지적은 **"수치마다 근거"** 였다. 다음 과제는 거의 처음부터 다시 했다.
