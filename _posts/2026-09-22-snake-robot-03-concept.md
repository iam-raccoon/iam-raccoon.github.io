세 번째 과제는 개념 형상이었음. 지난 피드백대로 시험 통로 치수를 먼저 정하고, 사용자 요구를 기능 요구로 나눈 다음 형상을 냈음.

## 전후진 원리

먼저 "관절 제어만으로 앞뒤가 제어되나?"라는 질문에 답했음.

서보가 시간차를 두고 굽으면 몸에 S자 파동이 생김. 각 마디는 바닥을 옆으로 밀고, 바퀴가 옆 미끄럼을 막으니 마디에 수직인 반력이 생김. 마디가 기울어 있어서 이 반력에는 전진 성분이 있음. 옆 성분은 번갈아 상쇄되고 전진 성분은 쌓임. 스케이트 날과 같은 원리임.

조작도 이 파동으로 함. 전진할 때는 머리 쪽 관절부터 굽혀서 머리 방향으로 감. 후진할 때는 순서를 뒤집어 꼬리 쪽 관절부터 굽힘. 조향은 파동에 오프셋을 줘서 좌우로 돌고, 속도는 파동 주파수로 조절함.

## 타겟 통로

통로는 폭 120mm, 높이 80mm, 굴절 반경 100mm, 단차 20mm 이하로 정했음. 진입 거리는 3~5m, 바닥은 평탄(경사 0°)으로 두었음.

폭 120mm는 파동이 차지하는 폭 98mm(요 7관절, 위상차 60°)에 양쪽 여유를 더한 값임. 높이 80mm는 로봇 40mm, 단차 20mm, 머리 들기 여유 20mm를 더한 값임. 단차 20mm는 바퀴 반경 8mm로는 굴러서 넘을 수 없어서, 피치 관절 2개로 머리를 들어 넘음.

하지만 이 숫자들은 로봇 크기에서 거꾸로 계산한 값이었음. 시나리오를 로봇에 맞췄다는 지적을 받고, 다음 과제에서 환경(실제 공극 실측)을 바탕으로 다시 뽑게 됨.

## 제약

- 서보 최대 토크 0.52N·m (XL330): 몸 전체를 들 수 없어서 피치 관절은 머리 2개만 둠
- 서보 전압 3.7~6.0V: 5V로 공급함. 테더가 길면 전압이 떨어져서 진입 거리에 상한이 생김
- 제어기 포트 합계 3A: 서보 버스에 외부 전원을 직접 분배함
- 테더 끌림: 5m에서 추진력 약 25% 손실
- 수동 바퀴: 경사와 험지에 약해서 바닥을 평탄으로 한정함

법과 제도 쪽으로는 소방장비 분류(탐색구조장비)에 잔해 공극 주행 장비 항목이 없었고, 강제 인증도 없었음.

## 기능 요구

사용자 요구 7개를 기능 요구 18개로 나눴음.

| 사용자 요구 | 기능 요구 |
|---|---|
| UR-1 좁은 공간 진입 | 통로 직진, 굴절 90°, 단차, 전진/후진/조향 |
| UR-2 요구조자 확인 | 전방 영상, 자체 조명, 영상 실시간 전송 |
| UR-3 위치 보고 | 진입 거리 추정 (관절 각도 적분), 진행 방향 표시 |
| UR-4 쉬운 조작 | 조작 입력 2개, 관절 각도 자동 생성 |
| UR-5 끼임 시 회수 | 후진 복귀, 관절 힘 해제, 테더 인장 회수 |
| UR-6 통신 유지 | 유선 통신, 유선 전원 |
| UR-7 고장 시 이동 | 관절 상태 감시, 고장 관절 제외 주행 |

임무 시나리오는 준비(자가진단), 진입, 굴절 90° × 4, 단차, 확인(조명, 촬영, 전송), 보고(진입 거리), 복귀(후진, 실패 시 테더 회수)의 7단계로 나눴음. 그리고 단계마다 기능 요구를 붙였음.

## 개념 형상

관절은 요 7개와 머리 피치 2개로 모두 9개이고, 수동 바퀴는 16개임.

- 배치: 꼬리 M0(제어기 OpenRB-150, 테더 인출), 추진부(요 관절 7, 수동 바퀴 16), 머리부(피치 2, FPV 카메라와 LED)
- 크기: 전장 약 550mm, 단면 약 35 × 40mm, 질량 약 320g
- 모듈: 추진부는 같은 모듈을 반복하고(하나 검증 후 복제), 제어기와 테더 인출은 꼬리 한 점에 모음

카메라는 아날로그 FPV(14 × 14mm, 먼 초점, 영상선 1가닥)로 골랐음. USB 내시경은 초점이 2~8cm로 고정이라 먼 표적이 흐리고, Wi-Fi 카메라는 잔해 속에서 끊김.

피드백에서 나온 앞바퀴 구동은 두 안을 비교하는 데까지만 했음. 모두 수동 바퀴인 A안은 파동을 칠 수 없을 만큼 좁은 곳에서 멈춤. 머리에 구동 바퀴를 단 B안은 구동력으로 빠져나올 수 있지만 서보가 하나 늘고 전류도 늘어남.

## 받은 피드백

- 시험 통로가 왜 그렇게 생겼는지(꺾임, 장애물 구간, 표적)를 무너진 건물 속 요구조자 같은 재난 상황으로 설명할 것
- 통로 폭을 로봇 한계에 맞춰 정하면 성공하려고 시나리오를 맞춘 것으로 보여서 검증해도 설득력이 없음. 시나리오상 왜 그 폭이 필요한지로 설명할 것
- 경사와 험지에 약하다고 평탄한 바닥으로 한정한 것은 재난 가정과 맞지 않음. 뱀 로봇을 왜 쓰는지부터 다시 생각할 것
- 서보는 어떤 후보군에서 왜 골랐는지를 같이 보일 것
- 요 관절 7개의 근거를 밝힐 것. 관절이 늘 때의 추진 이득과 제어, 공간 부담을 비교해 볼 것
- 90°로 꺾여 올라가는 곳을 지금 형상으로 넘을 수 있는지, 못 한다면 이론적으로 어떤 메커니즘으로 가능한지 논리를 낼 것. 뒤집혔을 때 롤 동작으로 바퀴를 아래로 되돌리는 식의 대응도 예로 나왔음
- GPS가 안 되는 곳에서 위치를 어떻게 아는지, 현장에서 꼬이는 유선을 어떻게 운용할지
- 스스로 판단하지 못하면 사람이 다 조종해야 하는데, 통신과 명령, 조작 방식이 아직 덜 다듬어졌음

지적의 공통된 요지는 시나리오를 로봇에 맞추지 말고 재난 상황에서 근거를 대라는 것, 그리고 실험으로 못 하는 것은 이론적 가능성이라도 보이라는 것이었음. 그래서 다음 과제는 거의 처음부터 다시 했음.
